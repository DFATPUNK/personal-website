This temporary sample exists to validate the publishing boundary. It is not a final personal essay, and it should be removed or replaced before the `v2` release to `main`.

It includes ordinary paragraphs, [an internal link](/essays), and enough Markdown structure to keep the renderer honest while the final writing is still absent.

## Renderer checklist

- Normal Markdown lists render with comfortable rhythm.
- Inline code such as `EssayLayout` stays readable inside prose.
- Long fenced code scrolls inside the block rather than widening the page.

```ts
type EssayLayout = 'standard' | 'immersive'

const defaultLayout: EssayLayout = 'standard'

const deliberatelyLongLine =
  'This line is intentionally long so the sample essay can verify horizontal scrolling inside a code block without causing global page overflow.'
```

The renderer also supports inline math, such as \(a^2 + b^2 = c^2\), and block math through KaTeX:

$$
f(x) = x^2 + 2x + 1
$$

| Mathematics | Present | Inline and block notation |
